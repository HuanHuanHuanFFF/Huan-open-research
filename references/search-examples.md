# 搜索与投入示例

以下均为假想情境，示范怎样让证据改变选择。数值、路线和预算不是默认设置，也不要求照搬示例中的动作。

## 1. 从收益目标倒推，改变优化对象

目标是显著减少总运行时间。当前提案反复修改同一个查找模块，但尚不清楚它占多少耗时。

**下一动作**：在有代表性的工作负载上测该模块及其他阶段的耗时占比，检查采样开销；用结果选择优化对象。

**假想观察**：该模块只占总耗时的 2%。在其他部分不变、没有连带收益的前提下，即使完全消除它，总耗时也最多减少 2%。

**决策变化**：若这不足以支持所需收益，转查更大的耗时来源，或寻找能同时减少多个阶段工作的表示变化。若小幅收益本身值得争取，仍可保留廉价局部优化。只有明确提出并检验了连带收益，才重新用这条路线解释更大的总收益。

## 2. 从一次失败提炼不同的下一步

当前路线通过扩大查找表减少计算，总运行时间却没有改善。

**已知与未知**：计算次数下降是观察；访存开销抵消收益是候选解释。其他解释还包括输入组成或测量波动。

**下一动作**：在控制输入与测量顺序的条件下，选择能区分这些解释的局部测量或不同表规模对照，先避免完整重写。

**条件决策**：若证据支持表访问成本成为限制，比较紧凑表示、分层访问或计算替代；若结果主要来自输入组成，按输入类别寻找适用范围；若仍被噪声遮蔽，先改善检测能力。证据不能区分解释时，不把其中一个写成既定原因。

**留下的起点**：保留已运行版本、测量条件和关键结果；新路线引用这些事实。记录“当前实现在哪些条件下受限”，而非“查表法永久无效”。

## 3. 给跨越短期退化的路线足够投入

新表示需要先构造共享中间结构，再让两个模块复用；仅实现构造会增加成本。旧路线已达到局部平台，但新路线是否值得做尚未确定。

**先检查关键依赖**：真实输入中是否存在足够复用，复用能省去多少工作，构造及维护成本可能有多大。小规模检验必须保留这些成本，不能用空操作制造可行性。

**阶段投入**：若初步证据支持，且预算足够完成首次有效检验，安排真实构造与至少一个消费路径的完整检查点，再评估扩展到第二个模块。中间产物暂时变慢不自动淘汰路线。

**重配条件**：若复用不足、维护成本抵消收益，或剩余预算已无法完成关键检验，则保留可复用部件和证据，暂停或换路。若组件分别有效，组合后仍需实测。

## 4. 数学研究中保留有用的旁支

原目标涉及任意规模的对象；有限搜索发现所有已见例子都有某种分解模式。

**下一动作**：把模式写成明确的中间猜想，查找满足原前提但破坏该模式的对象，并尝试证明该分解足以把目标归约到更小对象。

**条件决策**：若找到合法反例，调整分解条件或转向另一种表示；若归约成立，下一步攻克“任意对象都能这样分解”的桥接义务；若只有有限证据，保留其范围并继续寻找统一论证。

**可保留成果**：搜索程序、明确范围内的证书、已核验归约和仍待证明的条件。它们可以改变下一轮起点，即使原命题仍未闭合。
