# Huan Open Research

用于解决路线未知、需要多轮探索与反馈的研究任务。适用于算法与系统优化、机制探索、开放数学问题，以及已有研究的续跑。

核心是利用搜索中的多样性，控制评测中的偶然性：让尝试有实质差异，先投入足以获得有用证据的预算，再根据结果分配下一笔投入；单独复测候选，保留可运行或可核验的成果，让本轮发现改变下一轮搜索。

## 内容

- [SKILL.md](SKILL.md)：研究主流程。
- [实验与复测](references/experiments.md)：测量、选择偏差与成果验收。
- [数学研究](references/mathematics.md)：原命题、证明义务与证据范围。
- [搜索与投入示例](references/search-examples.md)：四个假想情境，说明证据如何改变路线选择。
- [交接、作业与时间窗](references/handoffs-and-windows.md)：跨执行者交接、外部作业回收及有截止窗口的运行与恢复，按条件加载。
- [工作流对照](references/evaluate-workflow.md)：检验本 skill 是否值得其额外开销。

## 使用

将 `SKILL.md` 与 `references/` 一起放入宿主支持的 skills 目录下的 `huan-open-research/` 文件夹，保留相对路径。使用时给出当轮目标、已有资料、真实预算和验收条件，例如：

```text
$huan-open-research
继续研究这个问题，先读取项目已有工件和实验记录。
本轮目标、预算和验收条件见当前任务要求。
```

## 当前状态

当前维护稿版本为 **0.2.3**。本次吸收已评审的真实项目记录，补清验收来源、早期完整路径测量、候选集成出口、证据复用及当前状态入口；交接、外部作业回收、截止和中断恢复按条件加载。保留既有投入判断和研究框架，不固定角色数量、模型、硬件、同步间隔或实验规模。

格式与引用检查只验证文档结构。真实任务使用、观察到的有效行为与故障、受控行为测试和等预算效果对照分别记录；v0.2.3 的受控行为测试和研究效果对照尚未运行，不宣称本 skill 已被验证能提高研究效率或胜率。

本版以用户指定的搜索、实验设计和资源分配方法为核心，吸收 huan-open-research v0.1 的证据分层与领域细则。它提供研究决策指导，实际评测、预算限制和权限由任务环境落实。
